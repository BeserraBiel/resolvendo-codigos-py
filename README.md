# Resolvendo Códigos em Python com GitHub Copilot 🚀

Este repositório contém as resoluções de desafios de lógica de programação em Python, desenvolvidos durante o curso da **DIO (Digital Innovation One)**. O diferencial deste projeto é a utilização do **GitHub Copilot** como assistente de codificação, explorando como a IA pode acelerar o desenvolvimento e sugerir soluções eficientes.

## 📌 Desafios Resolvidos

O projeto consiste em três scripts principais focados em lógica básica:

1.  **`concat_dados.py`**: Recebe dois dados distintos do usuário e os combina em uma única string utilizando f-strings.
2.  **`ope_mat.py`**: Realiza operações matemáticas básicas (soma, subtração, multiplicação e divisão) com base nos números e no operador fornecidos pelo usuário, incluindo tratamento de erros.
3.  **`repet_txt.py`**: Solicita uma string e um número inteiro para repetir o texto a quantidade de vezes desejada.

## 🛠️ Tecnologias Utilizadas

* **Python 3**: Linguagem principal para os scripts.
* **GitHub Copilot**: Ferramenta de IA para sugestão de código e otimização de lógica.
* **Git & GitHub**: Para versionamento e documentação.

## ⚙️ Como Executar os Projetos

Se você quiser testar os scripts localmente, siga estes passos:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/BeserraBiel/resolvendo-codigos-py.git](https://github.com/BeserraBiel/resolvendo-codigos-py.git)
    ```
2.  **Acesse a pasta do projeto:**
    ```bash
    cd resolvendo-codigos-py/resolucoes_code
    ```
3.  **Execute o script desejado:**
    ```bash
    python nome_do_arquivo.py
    ```

## 🧠 Aprendizados e Insights

Trabalhar com o GitHub Copilot neste desafio permitiu observar que:
* **Agilidade:** A IA reduz o tempo de escrita de estruturas repetitivas (como verificações `if/else`).
* **Refinamento:** É essencial revisar as sugestões da IA para garantir que os tipos de dados (int, str) estejam sendo tratados corretamente nas entradas (`input`).
* **Documentação:** A ferramenta é excelente para gerar comentários explicativos de forma automática, melhorando a legibilidade do código.
